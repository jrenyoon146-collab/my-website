# Personal Portfolio Website

## About This Project

This is my personal portfolio website. The main page is my resume, and the website also includes my hobbies and JavaScript calculator tools.

## Website Pages

### 1. Resume
**File:** `index.html`

This is the main page of the website. It contains:
- Contact information
- Skills
- Languages
- Education
- Experience
- Projects

### 2. My Hobbies
**File:** `hobby.html`

This page contains information about my hobbies and interests, including:
- Web Design
- Listening to Music
- Watching Movies
- Photography
- Traveling

The page includes a **Back to Resume** button.

### 3. JavaScript Tools
**File:** `distance.html`

This page includes:
- Temperature Converter
- Grade Calculator
- Change Calculator
- Distance Calculator

The page includes input validation for empty and invalid values.

## How to Run

Open `index.html` in a web browser, or visit the website using GitHub Pages.

## Navigation

- `index.html` → Main Resume Page
- `hobby.html` → Back to Resume
